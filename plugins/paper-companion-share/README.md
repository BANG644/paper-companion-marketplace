# Paper Companion · 论文研读助手

一个端到端的学术论文研读专家（Agent 型）：按意图检索文献（多源校验）、精读逐段中文转写、亮点与批判注记、引用脉络、可视化 HTML，多篇论文汇成**研读门户**（每篇一个深度解析页），并把所有笔记合并为单文件解析版全集（digest）。严守「绝不幻觉」铁律。

> 本仓库为**对外分享版**（v1.1.0）：已做信息脱敏，并把全部辅助脚本（原 `paper-explorer` 技能）打包进 `scripts/`，做到开箱即用、**核心链路零额外依赖**、无外部私有技能依赖。

## 类型

Agent 型（单个 AI 专家）

## 功能

- **结构化检索（发现模式）**：按你的研究意图（概览 / 全景 / 细节 / 前沿 / 经典 / 最新 / 综述）自适应检索，OpenAlex + arXiv + Crossref 多源交叉校验，可解释影响力评分，撤稿论文降权标记。
- **精读全流程**：背景调研 → 总体掌握 → 章节概览 → 分批逐段完整中文转写 → 要点导读 → 亮点与批判注记 → 引用脉络 → 术语表 → 沉淀。
- **可视化 HTML**：对复杂论文生成单文件自包含 HTML（结构地图 / 关键亮点 / 难点解析 / 术语表 / 引用脉络）。
- **研读门户与深度解析页（portal）**：多篇论文研读后，每篇生成一个**深度解析页**（八模块：一句话核心 / 真问题 / 核心直觉 / 方法拆解 / 关键结果 / 与你的关联 / 局限与可质疑处 / 定位与影响力 + 术语表，外加**按章节中英双语对照**与**原文 PDF 内嵌**），再由**总门户**统一组织（阅读计划 / 卡片导航 / 状态筛选）。
- **解析版全集（digest）**：把工作区内所有笔记合并渲染为一个响应式 HTML，并索引本地 PDF 原文、检索门户与研读门户。
- **分层记忆**：在当前工作区 `.paper-companion/` 沉淀笔记（浅 / 深两级），支持跨工作区主动检索。

## 快速开始

1. 把整个 `paper-companion-share/` 目录放到你的专家目录下（如 `~/.workbuddy/plugins/marketplaces/my-experts/plugins/paper-companion-share/`）。
2. 用 WorkBuddy 的注册命令让它可见（具体命令取决于你的平台版本；本包仅含专家内容，注册逻辑由宿主负责）。
3. **首次对话时，专家会自动做环境自检**（见下），缺什么引导你补什么——你基本不用手动折腾。

## 环境依赖与初始化引导

专家在首次运行或首次用到某项能力时，会**自动检测**以下依赖，并一步步引导安装；能自动装的自动装，必须你本人操作的部分（如代理端口、账号登录）会明确提示。完整手册见 `BOOTSTRAP.md`。

> **核心链路默认零额外依赖**：检索 / 下载 / 检索门户 / 解析版全集 / 研读门户解析页，用到脚本的部分全是 Python 标准库；解析页的双语对照由专家直接读 PDF 完成。下表第 4、5 项都是**可选**，缺失只影响速度或公网访问，不影响可用性。

| 依赖 | 作用 | 缺失时如何处理 |
|------|------|----------------|
| Python 3.8+ | 运行检索 / 下载 / 门户 / digest 脚本（纯标准库，零三方依赖） | 自动定位 `python3`/`python`；都没有则引导你安装 |
| 辅助脚本 `scripts/` | 检索 / 下载 / 门户 / digest（已随包附带） | 自动定位；若被移动，引导你指定目录 |
| 网络 / 代理 | 访问 arXiv / OpenAlex / Crossref 等外网学术 API | 受限网络下需配置代理（端口在你的 Clash 等客户端查看），专家会引导你填入 |
| PyMuPDF（可选加速器） | 一次批量处理多篇论文时，批量抽取英文原文文本 | **不装也能用全流程**；专家会说明这是加速项，你同意后才自动 `pip install pymupdf`；装不上就回退到直接读 PDF |
| `pinme` CLI（可选） | 仅当你要「把门户 / 解析版部署成公网链接」时才需要 | 自动 `npm install -g pinme`；`pinme login` 需你本人完成 |

**代理说明**：访问外网学术资源通常需要代理。端口请在你本机的代理客户端（如 Clash）中查看（常见为 `7890` 或 `7897`，以客户端显示为准）。专家会在检测到网络不可达时提示你，并把你提供的代理地址（如 `http://127.0.0.1:7897`）注入到后续脚本调用中，无需硬编码。注意：只有**联网**脚本（`search.py` / `download.py`）接受 `--proxy`；`build_portal.py` / `build_digest.py` 是纯本地渲染，不加该参数。

## 目录约定

- **你的原文**放在工作区根目录（PDF / 源文件 / 手写清单），文件名建议带年份前缀。
- **专家生成的派生内容**只写入 `<workspace>/.paper-companion/`（`papers/<标题>/`、`visuals/`、`index.md`、`digest.html`、`library/` 检索门户、`portal/` 研读门户等），绝不污染根目录。
- 其余工作各归其子目录，本专家不触碰、不混入。

## 与自用版的差异（分享版取舍）

本分享版由作者自用版同步而来，为了让任何机器都能顺畅跑通，刻意做了轻量化取舍：

- **保留**：检索 / 精读 / 可视化 / 解析版 digest / 研读门户与深度解析页 / 分层记忆 / 环境自检引导。
- **不含**：作者自用版依赖的**私有 HTML 看板索引服务**（依赖作者本机的私有技能与看板服务，他人机器上不存在）。分享版的公网访问走 `pinme` 部署或直接本地目录。
- **可选化**：作者自用版批量抽取 PDF 文本所用的 PyMuPDF，在分享版降级为**可选加速器**，默认用专家自身的 PDF 读取能力，保证零依赖可跑。
