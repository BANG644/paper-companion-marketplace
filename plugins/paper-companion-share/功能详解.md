# 论文研读助手 · 功能详解

> 一份按「操作逻辑顺序」梳理的功能说明，覆盖从**发现论文 → 解析论文 → 输出阐述**的完整链路，并包含产品的**友好性引导**能力。适用于对外介绍、企业宣传与新手上手。

---

## 一句话定位

论文研读助手是一位具备学术训练的研究伙伴：帮你**找得到**（按意图检索文献）、**读得懂**（逐段流畅中文转写 + 批判注记）、**讲得清**（单文件可视化 HTML、解析版全集与研读门户），并且**绝不幻觉**。

---

## 总览：一次完整使用会经历什么

```
① 意图判定 ── 你要"找方向"还是"读某篇"？
   │
   ├─ 发现类 ──▶ ② 结构化检索（发现模式）：多源校验找论文
   │                 │ 产出候选清单 → 你挑 1–3 篇交它精读
   │
   └─ 精读类 ──▶ ③ 解析论文（精读全流程）
                     背景调研 → 总体掌握 → 章节概览

                     → 亮点与批判注记 → 引用脉络 → 术语表 → 沉淀
                         │
                         ├─▶ ④ 可视化 HTML（复杂论文单文件可视化）
```

## 一、发现论文：结构化检索（发现模式）

当你给的是一个**研究方向 / 主题 / 关键词**（而不是某篇具体论文）时，进入发现模式。

**1. 意图自适应 —— 不是千篇一律按被引排序**
Agent 先读懂你的自然语言意图，再选对应检索策略。内置七种意图：

| 你的意图 | 策略侧重 |
|---------|---------|
| 想了解 / 入门 X | 综述层为主，先立骨架 |
| 全面了解 X 领域 | 三层：综述 + 奠基 + 前沿 |
| X 里某个具体方法 / 细节 | 精准命中 + 引文雪球（回溯它引了谁、追踪谁引了它） |
| 我熟悉 X，看最新进展 | 最新预印本为主，跳过综述 |
| X 的奠基 / 经典工作 | 高影响力排序（时间无关） |
| X 方向最新预印本 | arXiv 按提交时间倒序 |
| 找 X 的综述 | 标题级 survey / review 优先 |

**2. 多源交叉校验 —— 结果可信**
OpenAlex（主引擎）+ arXiv（补预印本）+ Crossref（校验 DOI 真实性）三方交叉，按 DOI / 归一化标题去重，每条标注「校验源」。

**3. 相关性闸门 —— 不堆高被引噪声**
按「查询实词覆盖率 + 标题命中率」各半计分，低于阈值直接剔除，避免"高被引但跑题"的论文顶到第一。

**4. 可解释影响力评分 —— 不黑箱**
FWCI（领域归一化）+ 全局引用百分位 + 同年引用百分位，三分量正交、各自可解释。**撤稿论文一律 0 分并打 ⚠️，排最后。**

> **本阶段亮点**：发现模式只产出候选清单并**建议你挑 1–3 篇**交它精读，不越权替你下结论。

## 二、解析论文：精读全流程

当你给的是某篇具体论文（PDF / arXiv·DOI 链接 / 具体标题）时，进入端到端精读。

**① 接入判定**
- PDF 文件：直接读全文；
- arXiv·DOI 链接：抓取全文；
- 仅标题：经代理调用 arXiv API 与 OpenAlex API 按标题精准定位（Google Scholar 仅作手动兜底，因反爬不稳定）。找不到如实告知。

**② 复用检查**
读取工作区 `.paper-companion/index.md`，若论文已读过，先问你「重跑全流程 / 仅回答追问」，并在旧笔记上续答，不重复劳动。

**③ 背景调研**
还原论文情境、影响力、定位与相关工作；凡论文未含且影响理解或有争议的点，检索权威信源，每条外部事实标注来源。

**④ 总体掌握**
用 1–2 段给出全貌：解决什么问题、核心贡献、方法主线、章节结构地图。

**⑤ 章节概览**
按章节输出概览性转写 + 每章一句话要点，轻量即时，帮你快速掌握骨架。

**⑥ 完整转写（分批）**
超长论文按 **10–15 页 / 批**逐批完整翻译，紧贴原文、专业自然、保留全部细节；批次间术语一致，每批完成通报进度，支持**中断后续做、断点续翻**。
- 术语渲染：先中文再括号补原词（如「注意力机制（attention mechanism）」），兼顾阅读速度与学术精度；
- 图表处理：不内联，仅标注「📊 原文此处有图/表，约显示：…」，由你回原文核对。

**⑦ 要点导读（每大部分）**
每个大部分（如 Method、Experiments）的转写完成后，配套结构化要点导读：该部分解决什么问题、核心机制 / 关键结论、与前后的关系、值得注意的细节。

**⑧ 亮点与批判注记**
以学术品味提炼创新点 / 方法巧思 / 意外结果 / 局限 / 开放问题，并给出「可质疑性」注记——证据是否充分、与已知工作是否矛盾、结论外推边界。

**⑨ 引用脉络（按需）**
提取参考文献，对每条被引论文经代理检索定位，输出「标题 · 年份 · 来源 · 一句话概览 · 摘要要点」，帮你先筛后读、链式深读。

**⑩ 术语表**
抽取关键术语中英对照，便于复读。

**⑪ 沉淀**
在 `.paper-companion/papers/<标题>/` 写入 overview / section-guides / translation / background / notes / citations 六份文件，并更新 index.md。

> **本阶段亮点**：
> - **逐段忠实**：完整转写不压缩、不合并、不改写为要点，长文也不丢失细节；
> - **断点续做**：分批机制记录进度，中断后从断点继续，不重复翻译；
> - **批判性思维**：不止"翻译"，更给可质疑性注记，帮你建立独立判断。

## 三、输出阐述：可视化、解析版全集与研读门户

读完后，把成果变成**好读、好存、好分享**的阐述材料。

**1. 可视化 HTML（按需，针对复杂论文）**
对含复杂重点 / 难点的论文，生成单文件自包含 HTML：
- 头部（标题 / 作者年份 / 摘要）+ 整体脉络（章节结构地图）+ 关键亮点 + 难点解析（白话拆解）+ 术语表 + 引用脉络；
- 单文件离线可开（CSS/JS 内联、无外部 CDN），响应式适配手机 / 电脑。

**2. 解析版全集 digest（默认交付层）**
把工作区**所有 Markdown 笔记**合并渲染成**一个自包含响应式 HTML**：
- 侧边目录 + 全文搜索 + 徽章 + 完整转写折叠；
- **本地文件索引**：根目录 PDF 原文 + `.paper-companion` 下全文 PDF + 检索门户 + 研读门户，相对路径可点击，标注类型与体积；
- 手机 / 电脑自适应，单文件离线可开。这是研读沉淀后的**默认最终交付**。

**3. 研读门户与深度解析页（portal）**
多篇论文研读后（同一工作区 ≥3 篇），默认交付形态升级为**「每篇一个深度解析页 + 总门户导航」**的可回访研读基地：

- **每篇一个深度解析页**，三标签页结构：
  - **深度解析**（八模块，缺一不可）：①一句话核心 ②真问题（为什么难）③核心直觉（白话拆解 + SVG 示意图）④方法拆解（SVG 结构图 + 白话伪代码）⑤关键结果（表格化，数字忠实原文）⑥**与你的关联**（结合你自己的科研 / 项目课题具体展开）⑦局限与可质疑处（证据充分性 / 结论外推边界）⑧定位与影响力 + 术语表；
  - **中英双语对照**：按章节手风琴分组，**左英右中分栏**；正文 ≤15 页做全文对照，>15 页做核心章节对照并明确标注未覆盖范围；关键段落后附要点卡，图表一律占位标注提示回原文核对；
  - **原文 PDF**：iframe 内嵌本地 PDF + arXiv / DOI / 项目页外链按钮；
- **总门户（index.html）**：个性化阅读计划（按难度梯度分阶段、标注每篇状态与读法）+ 论文卡片网格（状态徽章 / 难度星级 / 被引量级）+ 按状态筛选 + 清单核对报告 + 阅读方法论。
- **存放与部署**：产物统一下沉到 `<workspace>/.paper-companion/portal/`，整个目录可原样部署成公网链接。
- **灵活度**：单篇研读 + 你要网页交付时，直接产出同标准的单篇解析页，不强建总门户；综述类无实验节、博客类无 PDF 等情形允许模块变体（但八个信息维度都应有落点）。

**4. 论文门户 + 部署公网（可选，需你明确要求）**
当你搜到十几到几十篇、想打包成可浏览页面甚至公网链接时：
- 批量下载 PDF（并发、校验 `%PDF` 魔数避免存成假文件）→ 生成响应式 HTML 门户；
- 部署：`pinme upload` 生成 `https://<hash>.pinme.dev` 公网链接（目录上限 500MB）。
- 诚实标注：无开放获取的论文如实标「需机构权限」，**绝不编造全文链接**。

> **本阶段亮点**：
> - **一份顶全部**：digest 把零散笔记合并成单一可检索文件，告别"笔记散落各处"；
> - **可回访的研读基地**：研读门户让"读过就忘"变成"随时回看"，每篇都能深挖到方法级、对照到原句级；
> - **可索引、可追溯**：所有引用原文可点击回查，本地文件不移动、不改名；
> - **单文件自包含**：双击即开、离线可用，便于归档与外发。

## 四、贯穿全程：分层记忆沉淀

- **工作区内**：`.paper-companion/index.md`（索引 + 概览）+ `papers/<标题>/`（六份笔记 + 分批进度）；
- **用户级注册表**（轻）：记录各工作区读过的论文标题与日期，仅在跨工作区检索时由 Agent 主动调用；
- **分级**：浅（默认）= 索引 + 一句话概览；深（你明说"这篇重要"）= 亮点 + 详情 + 介绍。

> **亮点**：记忆只进专属子目录，**绝不污染你的工作区根目录**——根目录永远只放你自己的原文。

## 五、产品护城河：绝不幻觉

这是贯穿所有功能的铁律。任何来自论文之外的信息都必须标注可核查来源：
- 来源标注：`[论文本身]` / `[外部信源:URL]` / `[Agent推断]`；
- 不确定的写「未核实」，不编造数据、结论或引用；
- 检索失败如实告知，不补编造；无开放获取全文的论文如实标注，绝不伪造链接。

> 对学术场景而言，"可信"比"好读"更基础——这是本产品区别于普通翻译工具的核心。

## 六、友好性引导：开箱即用的初始化体验

考虑到分享后接收方的本地环境各异（可能缺代理、缺依赖），产品内置**环境自检与初始化引导**，让"能自动处理的全部自动完成，必须人工的才请你操作"。

**首次会话 / 首次用到某项能力时，Agent 自动检测五类依赖：**

| 依赖 | 作用 | 缺失时如何处理 |
|------|------|----------------|
| Python 3.8+ | 运行检索 / 下载 / 门户 / digest 脚本（纯标准库，零三方依赖） | 自动定位 `python3`/`python`；都没有则引导安装 |
| 辅助脚本 `scripts/` | 检索 / 下载 / 门户 / digest（已随包附带，无需另装技能） | 自动 `find` 定位；若被移动，引导你指定目录 |
| 网络 / 代理 | 访问 arXiv / OpenAlex / Crossref 等外网学术 API | 受限网络下需配置代理——**端口请在本机代理客户端（如 Clash）查看（常见 7890 / 7897）**，Agent 引导你填入后注入，不硬编码 |
| PyMuPDF（**可选加速器**） | 一次批量处理多篇时抽英文原文，更快更一致 | **不装也能跑全流程**（默认直接读 PDF）；Agent 会先说明这是加速项，你同意后才自动安装，失败则回退 |
| `pinme` CLI（可选） | 仅当你要「部署成公网链接」时才需要 | 自动 `npm install -g pinme`；`pinme login` 需你本人完成（账号授权不可代劳） |

**引导原则：**
- 检测到缺失 → 先说"检测到 X 未就绪，我来帮你搞定"，再给确切命令，能自动执行就自动执行；
- 必须人工的 → 说清"这一步需要你本人操作：（原因）"，并给可复制步骤，不模糊带过；
- **区分「必需」与「可选」** → Python / 脚本 / 网络缺失会阻断流程，必须解决；PyMuPDF / pinme 缺失只影响速度或公网访问，如实说明降级路径，不制造焦虑、不反复重试；
- 所有脚本调用统一用解析变量，**禁止写死绝对路径**，不假设你的机器与作者一致；`--proxy` 只给联网脚本（`search.py` / `download.py`），纯本地渲染脚本（`build_portal.py` / `build_digest.py`）不加该参数。

> **本能力亮点**：
> - **零门槛上手**：辅助脚本随包附带、依赖自动发现，**核心链路零额外依赖**，接收方基本无需手动折腾；
> - **诚实透明**：代理、登录这类"只有你能做"的环节，明确告知并给清晰路径，而不是假装能代劳；可选件缺失时讲清降级方案，不卡流程。

## 核心亮点速览

1. **找得准**：意图自适应检索 + 多源校验 + 相关性闸门 + 可解释影响力评分，撤稿自动降权。
2. **读得深**：逐段忠实中文转写、分批不断点、配套要点导读与批判性注记。
3. **讲得清**：单文件可视化 HTML + 默认交付的解析版全集 digest + 多篇研读门户（逐篇深度解析页 + 中英双语对照 + 原文 PDF 内嵌），可索引、可离线、可分享。
4. **记得住**：分层记忆只进专属目录，不污染工作区。
5. **信得过**：绝不幻觉，所有外部信息可溯源。
6. **用得爽**：内置环境自检与初始化引导，**核心链路零额外依赖**、开箱即用。

## 七、分享版说明（与自用版的差异）

本分享版由作者自用版同步升级而来。为了让**任何机器**拿到后都能顺畅跑通，做了一组刻意的轻量化取舍：

| 能力 | 分享版处理 | 原因 |
|------|-----------|------|
| 检索 / 精读 / 可视化 / 解析版 digest | **完整保留** | 核心链路，零额外依赖即可跑 |
| 研读门户与深度解析页 | **完整保留** | 多篇场景的默认交付形态 |
| 分层记忆 + 跨工作区检索 | **完整保留** | 记忆只进 `.paper-companion/`，不污染工作区 |
| 环境自检与初始化引导 | **完整保留（分享版特有）** | 接收方环境各异，必须自动兜底 |
| PDF 文本批量抽取（PyMuPDF） | **降级为可选加速器** | 自用版把它当必需项；分享版默认用专家自身读 PDF 能力，装不上也不影响可用性 |
| HTML 看板索引服务 | **不含** | 依赖作者本机的私有技能与看板服务器，他人机器上不存在；公网访问改走 `pinme` 部署或本地目录 |
